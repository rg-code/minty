    New user
    1. In the Cloudflare dashboard open Workers & Pages → minty → Settings → Variables and secrets and set the variable MINTY_USERS to the value below (first line).
    2. Add their Plaid keys there as secrets. Each person needs their own Plaid Trial keys; only the first slot is required. Each further slot is another Plaid Trial account, used once the ones before it reach the 10-login cap (slots come from PLAID_SLOTS). Or from a terminal in your fork, use the wrangler secret put commands below.
    3. So they can sign in, add their email to the Access policy (Zero Trust → Access → Applications → minty), and to ALLOWED_LOGINS if you set one.
    4. No restart needed: saving creates a new version of the Worker right away.
    
    
    
    Once saved, they appear on the dashboard and on
