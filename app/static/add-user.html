Add a user

People are set up in .env on the Minty host, so their Plaid keys never pass through the browser. Fill in a name and Minty writes the exact lines to add.

    New user
    1. On the Minty host, open .env and replace (or add) the MINTY_USERS line, then add the new Plaid keys. Each person needs their own Plaid Trial keys; backup is optional and only used once primary reaches the 10-login cap.
    2. So they can open Minty, append their Tailscale login to ALLOWED_LOGINS (comma-separated).
    3. Restart the app so it picks up the change: 
      docker compose up -d --force-recreate api
    
    
    
    After the restart, they appear on the dashboard and on
      Add account.
